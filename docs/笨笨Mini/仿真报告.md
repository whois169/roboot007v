# 笨笨 Mini（BB-01）仿真报告

> 第 1 版，2026-10-16。第 3 步：用 MuJoCo 仿真验证电机够不够、会不会翻。
> 程序：`bb/sim/export_mujoco.py`（从 CAD 生成仿真模型）、`bb/sim/run_sim.py`（跑场景）、`bb/sim/lift_plan.py`（抬腿姿势规划）。
> 完整数字：`bb/out/sim_report.txt`。3D 回放：https://claude.ai/artifact/Hr9vptZPw8y4d6ifZNE8aL （“仿真回放”页）。

## 一、仿真里是怎么建的
| 项 | 怎么做的 |
|---|---|
| 重量、重心、惯量 | 从 CAD 实体逐个零件算（重量表在 `bb/config.py`），自重 15.6 kg + 货 10 kg = 25.6 kg |
| 麦轮 | 每个轮子 12 个 45° 滚子，每个滚子都能自由转（按真实麦轮的“桶形”滚子外形），X 形布置 |
| 髋关节 | 5840 蜗轮 × 3:1 同步带，位置控制，合格线按额定 20.7 N·m |
| 轮子电机 | GIM4310-10，峰值 5.6 N·m；转得越快能出的越少（24V 电压限制：150 转/分时 2.05，228 转/分时 0） |
| 头 | 总线舵机，上限 1.9 N·m |
| 地面 | 摩擦系数 0.9（聚氨酯滚子在地砖、水泥地上大概这个数） |
| 货 | 10 kg，在货斗中间，重心高出甲板 10 cm |

## 二、结果（都是背着 10 kg）
| 场景 | 关键数字 | 结论 |
|---|---|---|
| 站着不动 | 髋 前 4.3 / 后 5.5 N·m；轮子分重 前 5.8 / 后 7.0 kg | ✓ 蜗轮自锁，站着不耗电 |
| 折叠 → 站起来 → 趴下 | 髋最大 11.4 N·m，站起来 3.1 秒 | ✓（要按第三节第 1 条控制） |
| 加速到 1.4 m/s | 轮子最大 1.0 N·m，匀速 0.54 N·m，速度跟得上 | ✓ |
| 急停（4 m/s²） | 实际减速 3.6 m/s²，37 cm 停住，后轮还压着 1.4 kg | ✓ 不会往前翻 |
| 10% 坡 | 上坡匀速 1.21 N·m（额定 2.05），停在坡上 0.6 N·m、不溜 | ✓ |
| 横走 0.5 m/s、原地转 90°/秒 | 实际 0.49 m/s、89°/秒，不跑偏 | ✓ 麦轮能真横走 |
| 0.8 m/s 压 15 mm 门槛 | 过得去；髋冲到 17.3 N·m，轮子 3.4 N·m | ✓ 但余量小（见第四节） |
| 抬一条腿 | 先调姿势：四条腿都能抬 10 cm 以上，另外三个轮子最少还压着 3 kg | ✓ |
| 直接抬腿（演示） | 不调姿势直接抬后腿：抬不起来，整个车歪 39° | ✗ 所以必须先调姿势 |

**电机选型不用改**：轮子电机和髋驱动在所有场景里都在额定以内，最紧的是“过门槛”时的髋（17.3 / 20.7）。

## 三、仿真得出的控制规矩（以后写底盘 ESP32 程序时要照做）
1. **站起来、趴下时，轮子接地前后放慢**：摆臂角在 −11°…+5° 之间（轮子接地是 −3.4°）把髋速度降到 20°/秒，其余 80°/秒。不放慢的话，25 kg 一下子被“拽”起来，髋冲到 17.4 N·m；放慢后 11.4。
2. **髋不能一下子全速**：从停到 80°/秒 要有个加速过程（仿真用 300°/秒²，约 0.27 秒）。
3. **急停也要“软”一点**：减速度在 0.1–0.2 秒里加上去，不要瞬间跳到最大，不然后轮会被甩得差点离地。
4. **过门槛、地砖缝慢一点**：15 mm 门槛 0.8 m/s 过，髋冲到 17.3 N·m；降到 0.3 m/s 只有 10.4。以后深度相机看到门槛就自动减速。
5. **调腿的姿势时，轮子松开**：摆臂一动，着地点要前后滚，轮子锁着会顶着劲；姿势到位后再锁住轮子。
6. **抬腿前先调姿势**（下一节）。

## 四、抬一条腿
每条腿只有一个髋关节，抬腿前没法像四足那样把重心挪开。重心刚好在四个轮子中间，对角线差不多从它下面穿过：
- 其他腿不动、直接抬：满载时前腿 +11 mm（勉强在里面）、**后腿 −13 mm（在外面，会歪倒）**；空车反过来。这点余量太小，实际一颠就倒。
- **先调姿势再抬**：抬哪条腿，就把**同一侧的另一条腿收到 100°**（轮子收到身体下面），**对面两条腿放到 50–65°**。车身只歪 3–7°，重心离三个着地轮围成的三角形的边约 **5 cm**，抬 10 cm 以上都稳。

| 满载抬哪条 | 另外三条腿 | 车身歪 | 重心离边 | 髋最大 |
|---|---|---|---|---|
| 前左 | 前右 65° / 后左 100° / 后右 65° | 2.5° | 53 mm | 6.5 N·m |
| 前右 | 前左 65° / 后左 65° / 后右 100° | 2.5° | 53 mm | 6.5 N·m |
| 后左 | 前左 100° / 前右 50° / 后右 50° | 7.1° | 50 mm | 12.5 N·m |
| 后右 | 前左 50° / 前右 100° / 后左 50° | 7.1° | 51 mm | 12.6 N·m |

（静力计算；后左、前左两种在仿真里实际跑过，三个支撑轮最少还压着 3.2 / 4.3 kg。）

**还没做的**：上 8–10 cm 台阶的完整动作（抬前腿搭上台阶 → 往前开 → 抬后腿），第一代先不做，以后在这个基础上仿真。

## 五、要注意的
1. **髋是“硬腿”**：蜗轮自锁，颠簸全靠轮子吸收，冲击直接到蜗轮齿上。15 mm 门槛 0.8 m/s 就用掉 84% 的额定扭矩。建议：
   - 程序上：看到门槛减速（上面第 4 条）；
   - 结构上：同步带张紧轮做成弹簧张紧，或者大带轮和髋轴之间加橡胶缓冲，让腿有一点点弹性（第 4 步出图时一起设计）。
2. **仿真和真机的差别**：冲击力的大小取决于轮子和地面有多“软”，仿真里只是估算；滚动阻力按滚子轴承摩擦估的。**样品到了以后**按选型计算书第五节实测，把数字填回去重新跑。
3. 头部舵机、雷达、屏幕这些在仿真里只算了重量，没算它们自己的动作。

## 六、怎么重新跑
```bash
python bb/build.py                      # 改了 CAD 尺寸先跑这个
python bb/sim/run_sim.py --export       # 重新生成仿真模型并跑全部场景（约 1 分钟）
python bb/sim/run_sim.py lift_RL        # 只跑一个场景
```
跑完会自动更新 3D 回放用的数据（`bb/out/bb01_data.js`），重新发布查看页就能看到。
