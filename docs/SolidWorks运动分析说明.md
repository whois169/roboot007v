# 用 SolidWorks 做运动分析

## 用哪个文件
- **`out/solidworks/robodog_v0.4_rigid_groups.step`**：做运动分析用这个。
  - 所有零件都在**零位**：腿竖直向下，头朝正前。
  - 已经按 15 个运动刚体分成 15 个子装配，每个子装配内部是一个整体，不会乱动。
- `out/solidworks/groups/*.step`：同样的 15 个刚体，每个单独一个文件，想一个一个插入时用。
- `out/step/robodog_v0.4_stand.step`：站立姿态整机。只适合看外观和出图，**没有分组**，不要拿来做运动分析。
- `out/solidworks/关节表.csv`：14 个关节的轴线位置、方向、转动范围，以及站立、转头、坐下、趴下时的角度。
- `out/solidworks/刚体质量.csv`：每个刚体的估算质量和重心，可以在 SolidWorks 里用"覆盖质量"填进去。

坐标系：X 向前，Y 向左，Z 向上，单位 mm，原点在机身中心、髋关节高度。
SolidWorks 默认 Y 向上，打开后狗会"侧躺"着，这不影响分析。也可以在导入选项里把 Z 轴设为向上。

## 15 个刚体
| 刚体 | 说明 |
|---|---|
| body | 机身：所有固定件，包括 4 个外摆电机的外壳、偏航电机定子、电池、电子件、装甲 |
| FL/FR/RL/RR_haa | 髋支架组：髋支架、HAA 法兰、HFE 电机外壳 |
| FL/FR/RL/RR_hfe | 大腿组：大腿内外板、KFE 电机、带轮、皮带、张紧轮、膝轴、大腿装甲 |
| FL/FR/RL/RR_knee | 小腿组：小腿、36T 大带轮、护甲、足端 |
| neck_yaw | 脖子偏航：偏航转子、轭架、俯仰电机定子 |
| neck_pitch | 头部：俯仰转子、头部框架、头壳、头内电子件 |

FL = 前左，FR = 前右，RL = 后左，RR = 后右。

## 配合步骤（每个关节一个"铰链"配合）
1. 打开 STEP。导入选项里勾选"导入为装配体"。
2. 把 `body` 设为**固定**，其余 14 个子装配设为浮动。
3. 每个关节加一个**铰链（Hinge）配合**。铰链配合要选两组面：
   - "同轴心"栏选两个圆柱面，见下表
   - "重合"栏选两个贴在一起的端面，比如电机法兰端面和打印件的贴合面
   
   这样一次就同时定了同轴和轴向位置。`关节表.csv` 里也有这张表：

| 关节 | 父 → 子 | 同轴心选这两个圆柱面 |
|---|---|---|
| ×_haa（外摆） | body → ×_haa | HAA 电机外圆柱面 ↔ HAA 法兰圆柱面 |
| ×_hfe（髋俯仰） | ×_haa → ×_hfe | HFE 电机外圆柱面 ↔ HFE 法兰圆柱面 |
| ×_knee（膝） | ×_hfe → ×_knee | 膝轴圆柱面 ↔ 小腿轮毂内孔 |
| neck_yaw | body → neck_yaw | 偏航电机定子 ↔ 偏航电机转子 |
| neck_pitch | neck_yaw → neck_pitch | 俯仰电机定子 ↔ 俯仰电机转子 |

4. 在铰链配合里勾选"角度限制"，按 `关节表.csv` 里的上下限填。
5. 同步带不用加配合：两个带轮都固定在大腿组上，皮带跟着大腿一起动。膝电机到小腿的 1:1.8 传动比，在马达设置里体现就行。

## 运动分析（Motion Study）
- 需要 SOLIDWORKS Premium 或 Professional，并在"插件"里启用 **SOLIDWORKS Motion**。没有这个插件的话，只能做"动画"，看运动过程，不能算力和力矩。
- 算例类型选"Motion 分析"，然后：
  - 加**重力**（-Z 方向，如果导入时没改坐标轴）
  - 加一个地面平面，4 个足端和地面之间加**接触**，摩擦系数先填 0.6，相当于软胶对瓷砖
  - 每个关节加一个**旋转马达**，类型选"位移"，按 `关节表.csv` 里的角度做插值。比如从站立的 35° / -70° 过渡到坐下的角度
- 结果里看每个旋转马达的**力矩**：
  - 外摆、髋俯仰：电机直接驱动，峰值力矩应低于 7 N·m，持续力矩低于 3 N·m
  - 膝：皮带有 1.8 倍减速，所以膝关节力矩要先除以 1.8，再对照电机的 7 N·m 峰值和 3 N·m 额定
- 质量：SolidWorks 默认按材料算质量，打印件会算成实心，结果偏重。建议用 `刚体质量.csv` 里的值给每个刚体"覆盖质量"。

## 注意
- 电机、云台电机、电子件都是**简化外形**，孔位是占位值。拿到达妙官方的电机 3D 模型以后，替换进去再出工程图。
- 改完 `cad/config.py` 里的孔位，重新运行 `python3 export_sw.py`，这一套文件会全部重新生成。
