# 底盘程序说明（机械狗007v）

> 写底盘 ESP32 固件、改底盘逻辑的人看这份。代码在 `007v/chassis/`：
> - `protocol.py` —— 大脑 ↔ 底盘的指令和事件格式（和头部一样，一行一条 JSON，115200）
> - `controller.py` —— 底盘程序本体：**Python 参考实现**，只用 math，测通以后照着翻成 C++ 烧进底盘 ESP32-S3
> - `virtual.py` —— 虚拟底盘：MuJoCo 仿真的车 + 底盘程序（大脑没有真车时用它）
> - `test_chassis.py` —— 28 项仿真测试，改了底盘程序必须跑：`python 007v/chassis/test_chassis.py`（约 15 秒）

## 硬件怎么接
- 底盘 ESP32-S3 ←USB→ 树莓派（大脑）
- ESP32 ←CAN（经 CAN 收发小板）→ 4 个 GIM4310-10 轮子电机：发目标转速，收转速、扭矩
- ESP32 →PWM→ 4 个髋电机驱动（5840 蜗轮电机）；ESP32 ←I2C（经分路器）← 4 个 AS5600 读髋角度；髋的位置环在 ESP32 里做
- 急停按钮一路直接断电机电源（硬件），另一路接 ESP32 的一个脚，让程序知道
- 电池电压分压后接 ESP32 的 ADC

## 程序每 5 ms 做的事（`Controller.update`）
1. 读传感器：髋角度、轮子转速和扭矩、急停脚、电池电压
2. 里程计：四个轮子转速 → 车身速度（最小二乘）→ 积分出位置和朝向
3. 急停、断线（2 秒没收到大脑任何一行）、电量低检查
4. 按当前模式算目标车身速度：drive（大脑给的速度，0.5 秒不续就停）/ move（按剩下的距离算，快到提前减速）/ pose（站起来、趴下）
5. 限加速度：加速 0.5、刹车 1.0 m/s²；急停 0.1 秒内从 1 加到 4 m/s²（一下子到 4，车往前栽、后轮瞬间失重）
6. 车身速度 → 四个轮子目标转速：ω = (vx + s·vy + wz·(s·x − y)) / r；某个轮子超速就整体按比例降
7. 髋卡住检查：目标和实际差 15° 超过 1 秒 → 故障 HIP_STALL，原地不动
8. 载重估计（只在直着加速、刹车时）：轮子总推力 F = Σ扭矩 / r，拟合 F = m·a + b，m 减空车的 m 就是背上的重量
9. 每 0.1 秒发一次状态

## 规矩（都来自仿真，见 `仿真报告.md`）
| 项目 | 值 | 为什么 |
|---|---|---|
| 最高速度 | 1.1 m/s | 110 轮 + GIM4310-10 的上限；大脑在家里只用 0.4 |
| 横走 / 原地转 | 0.2 m/s / 90°/秒 | 左右两边没有台阶测距，横着走看不到旁边的台阶，所以慢一点 |
| 加速 / 刹车 / 急停 | 0.5 / 1.0 / 4.0 m/s² | 急停 4 m/s² 时后轮还压着约 6 kg，不会往前翻 |
| 站起来、趴下 | 髋 80°/秒，加速度 300°/秒²；轮子接地（约 −3.4°）前后 ±8° 放慢到 20°/秒 | 不放慢的话 25 kg 一下子被拽起来，髋冲到 17.8 N·m |
| 过门槛 | 台阶测距看到坎，底盘自己限速 0.3（大脑也可以发 `limit 0.3`） | 0.8 m/s 压 15 mm 门槛髋冲到 20.2 N·m（上限 20.7） |

| 台阶测距板没回应 | 限速 0.2，报 STEP_SENSOR | |
| 只能停稳了站起来、趴下 | 走着时回 MOVING | |
| 趴着不能走 | 回 FOLDED | 大脑会自动先发 stand |

## 仿真测试结果（`test_chassis.py`，47 项全过）
- 站起来 3.3 秒，机身离地 134 mm，髋最大 11.1 N·m；趴下后坐在滑撬上
- 往前 1 米实际 0.996 米、不跑偏；左转 90° 实际 88.8°；横走 0.5 米实际 0.49 米
- 最高速 1.10 m/s；限速 0.3 时 0.30；drive 断了自己停；断线 2 秒自己停
- 1 m/s 软急停 16 cm 停住，后轮最少还压着 5.8 kg
- 载重：背 10 kg 估 9–10 kg，空车估 0
- 全速（1 m/s）冲向前面 1.2 米处的楼梯边：自己刹住，前轮离边还有 87 mm；锁住后往前开不动，往后退可以，退开自动解锁；用 move 走过去半路停下（why = CLIFF）
- 前面一道 15 mm 门槛：报 STEP（估 15 mm），自己限速到 0.30
- 一个测距板坏了：报 STEP_SENSOR，限速 0.20；横着走最快 0.20
- 灯：平时、刹车、倒车、充电、急停都按上表亮

## 到货以后要做的
1. **翻成 C++**：`controller.py` 一行行对着翻（没有用 numpy），CAN 和 PWM 的收发另写一层。
2. **髋的位置环**：仿真里是理想的 PD，真电机要在 ESP32 里调 PID（先空载、再带载）。
3. **轮子方向**：四个 GIM4310 装好后，先发 drive 0.1 m/s，看四个轮子是不是都往前转；反了就在固件里把那个轮子的符号取反。
4. **载重标定**：空车前后各走 1 米，状态里 `load` 应该是 0；不是 0 就把 `M_EMPTY` 加上这个数。
5. **台阶测距标定**：站在平地上、停稳，大脑发 `{"calib":"step","id":1}`，底盘记住这时的读数当"平地"。
6. **电池曲线**：`bat_pct` 是 6S 锂电的粗略曲线，拿实际电池充满、用到保护板断电，记几个点改掉。
