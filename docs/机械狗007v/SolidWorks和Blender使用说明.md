# 机械狗007v：用 Blender / SolidWorks 看模型、拆散、做运动

> 先说清楚：**外壳还没画**，现在打开看到的是“骨架”（铝板机身、摆臂、麦轮、三段式头部、货斗）。和效果图比，看的是**比例、布局、折叠方式**，不会一模一样；分缝、灯带、装甲这些等外壳设计时再加。

## Blender（已装好 5.2）
1. 双击 `机械狗007v.blend` 打开。中间是 3D 视图，下面是时间轴。
2. **按空格播放**（再按一次停）。时间轴上有标记，点一下就跳过去：
   - 展开站着 → 折叠 → 折叠好了 → 展开（站起来）
   - 抬头 / 低头
   - 拆散 → 停住看 → 装回
   - 仿真回放 8 段：站着不动、折叠 → 站起来 → 趴下、加速和急停、10% 坡、横走和原地转、压门槛、直接抬后左腿（会歪倒）、调姿势后抬前左 / 后左腿
   - 仿真那几段是 MuJoCo 算出来的真实动作，速度是真实速度。
3. **转着看**：鼠标中键拖动转视角，滚轮缩放，Shift + 中键平移；小键盘 1 / 3 / 7 是前 / 右 / 顶视图；按 0 是相机视角。
4. **自己拆散**：先把时间轴拖到最开头（“展开站着”那段），在右上角大纲里点“拆散控制”，按 **N** 打开侧栏 → “物体”页 → 最下面“自定义属性”里的 **拆散**，从 0 拖到 1 就拆开了。
5. **自己转关节**：在大纲“关节”里选“前左摆臂（转轴）”之类，按 **R X** 再输入角度（比如 `-30` 回车）。头是“屏幕头（转轴）”，轮子是“前左麦轮（转轴）”。播放动画时关节会被动画带回去；想自由摆姿势，先把时间轴停在某一帧再改。
6. **只看某一部分**：大纲里“机身零件 / 摆臂零件 / 麦轮零件 / 屏幕头零件”前面的眼睛，点一下就隐藏这一类。
7. **出图**：按 **F12** 渲染当前帧（Eevee），渲染窗口里“图像 → 另存为”保存。

## SolidWorks（这台电脑上主程序没装，只有 eDrawings；在有 SolidWorks 的电脑上用）
1. **打开**：文件 → 打开 → 文件类型选 STEP → 选 `机械狗007v_装配体.step`。导入选项里把“Z 轴向上”勾上（不勾的话狗会侧躺，不影响用）。
2. 左边设计树里有 10 个子装配：`01_机身部件` … `10_后右麦轮部件`。每个子装配是一个整体（一个运动部件）。
3. **加铝链配合（让它能转）**：每个转轴两边各有一个 Φ6 的小圆柱，叫“铰链标记-xx（机身侧 / 摆臂侧 / 麦轮侧）”。
   - 先把机身固定（右键 → 固定）。
   - 配合 → 机械配合 → **铰链**：圆柱面选两个铰链标记的外圆，重合面选它们的端面。
   - 一共 9 个铰链：4 个髋（机身 ↔ 摆臂）、4 个轮（摆臂 ↔ 麦轮）、1 个头（机身 ↔ 屏幕头）。
   - 角度范围看 `关节表.csv`：髋 -110°（折叠）～ 100°，行驶 55°；头 -35°（抬头）～ 20°（低头）。
4. **爆炸视图（拆散）**：插入 → 爆炸视图，选零件拖箭头；或者用“自动间距”一次拆开一组。
5. **运动算例**：底部“运动算例”标签 → 类型选“动画”（所有版本都有）或“Motion 分析”（要 SOLIDWORKS Premium / Motion 插件）→ 在铰链上加“旋转马达”，按 `关节表.csv` 的角度设动作。要算受力就用 Motion 分析，质量按 `部件质量.csv` 在零件属性里“覆盖质量”。
6. 仿真结论（扭矩、会不会翻）我们已经用 MuJoCo 算过了，见 `docs/机械狗007v/仿真报告.md`；SolidWorks 里主要用来看配合、检查干涉、做爆炸图和动画。
