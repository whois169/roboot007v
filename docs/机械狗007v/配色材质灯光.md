# 机械狗007v 配色、材质、灯光（2026-10-18 定稿：方案 B 浅色版）

结构和比例不变（外观定稿 v4），只定颜色、材质和灯。全车不用金色。改之前的版本存档在 git tag `配色前存档`。
颜色表在 `007v/look.py`（3D 查看页、glb、Blender 共用）；效果图用 `007v/blender/render_color.py` 出（A / B 两套都能出，加 `night` 出夜间图）。

## 配色（外壳比骨架浅）
| 部位 | 颜色 | 材质 |
|---|---|---|
| 外壳、顶板、臂座外壳、打印盖板 | 浅灰白 #D9DBDD | 哑光喷涂，细颗粒 |
| 骨架、连杆、边梁、电机、电机护罩、深色盖板 | 深灰 #3D4247 | 深色阳极氧化铝，轻微金属光泽 |
| 螺栓、轴承座、轴毂、轮子侧板、字样 | 金属灰 | 拉丝金属 |
| 麦轮滚子、线缆、触边 | 黑 | 橡胶 / 编织护套 |
| 屏幕、传感器窗口、相机窗 | 烟黑 | 玻璃，带反光 |
| 原来的金色线条 / 金色件 | 比所在部件深一级的灰：外壳上 #A6AAAE（臂座箍、栏板压条），深色件上 #25282C（摆臂斜纹、边线、髋盖圈） | 同所在部件 |

方案 A（深色版：外壳石墨灰 #5C6268、骨架近黑 #1B1D20）没选，脚本里留着可以再出图对比。

## 灯（每个都有用处，亮度适中）
| 灯 | 颜色 | 用处 |
|---|---|---|
| 表情屏眼睛 | 青 | 交互、表情 |
| 头部转轴光环、麦轮轮毂光环、电机端面光环 | 青 | 看得出哪个关节 / 轮子在动、是否通电 |
| 机身两侧腰线灯带 | 青 | 电量 / 状态，侧面的人也看得到 |
| 前保险杠两个方框 | 白 | 照明：给深度相机补光、夜里照路 |
| 尾部两盏 | 红 | 后面的人看得到它；刹车 / 倒车提示 |

不点亮：底部灯槽、腰线前后端头、头上的隐私指示灯（做成烟黑窗口，录音 / 录像时才亮，以后定颜色）。
注意：侧面腰线灯现在每边两段（各 70 mm），还没连成一整条。
