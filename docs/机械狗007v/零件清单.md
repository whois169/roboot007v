# 机械狗007v 零件清单

> 由 `007v/bom.py` 生成（改清单改那个文件，再跑 `python 007v/bom.py`）。价格是国内零售大概价，以下单时为准。
> 批次：**样品** = 先各买 1 个测试（选型计算书第五节）；**第二批** = 样品测过、图纸改好再买；**已有** = 旧项目沿用；**以后** = 现在不买。

**样品这一批约 3472 元；样品合格后第二批约 3527 元**（不含已有的树莓派、头部传感器，不含以后的深度相机）。

## 下单时要问卖家要图的（★）

这几样的安装孔位网上查不到，图纸里先按常见规格画、标了 ★。下单时请卖家发**安装尺寸图（PDF 或 STEP）**，拿到后发给我，我改图：

- **轮子电机**（SteadyWin GIM4310-10 V1.1（自带驱动 + 编码器，CAN））：背面安装孔、输出法兰孔、止口直径要卖家的安装图；图纸 A06、B03 等它
- **麦克纳姆轮（一套 4 个）**（152 mm（6 寸）铝合金麦轮，轴承滚子，宽 45，15 个滚子，左右各 2）：80 宽的“重载款”单个 2.3 kg、宽 79，太宽太重，不要买；轮毂孔位问卖家要图（图纸 B03）
- **髋蜗轮电机**（5840 金属齿轮蜗轮蜗杆减速电机，24V，约 40 转/分，带霍尔编码器，自锁）：同叫 5840 的参数差很多，以卖家规格书为准；箱体输出面 4 个 M4 孔位问卖家要图（图纸 A01 的长孔）
- **屏幕板**（微雪 ESP32-S3-Touch-LCD-4.3B（800×480，触摸））：只当显示屏（HUD），通过 USB 接树莓派；它的引脚几乎全被屏幕占了，接不了传感器；孔位在官方图纸包里
