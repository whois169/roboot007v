# 机械狗007v 接线图

> 由 `007v/wiring.py` 生成；图在“机械狗007v 图纸”网页的“接线图”页。引脚是建议值，写固件时再定。

## 供电

```
电池 6S2P（22.2V）─ 主保险 30A ─ 总电源继电器 K1（总开关控制线圈）─┬─ 24V 总线（不经过急停）
                                                                  │    ├─ 5A ─ DC-DC 5V 5.5A ─ 树莓派 5（GPIO 5V 脚）
                                                                  │    ├─ 3A ─ DC-DC 5V 3.2A ─ 头部 USB 集线器、雷达、底盘 ESP32
                                                                  │    └─ 3A ─ DC-DC 12V ─ 头部舵机
                                                                  └─ 电机继电器 K2（线圈串急停常闭）─ 24V 电机电源
                                                                       ├─ 5A ×4 ─ 轮子电机 ×4
                                                                       └─ 10A ×2 ─ 髋驱动 BTS7960 ×4
```

- **急停只断电机，不断大脑**：按下急停，K2 断开，8 个电机全部断电（髋是蜗轮自锁，不会塌）；树莓派和 ESP32 照常工作，知道发生了急停。
- 总开关和急停都只控制继电器线圈（几十毫安），大电流不走按钮。
- INA226 的分流电阻串在电池负极，读电池电压、电流，算剩余电量。

## 信号

- 树莓派 5 USB：头部集线器（屏幕板、头部传感器 ESP32、相机）、底盘 ESP32、雷达、深度相机（以后）。
- 底盘 ESP32 → CAN → 4 个轮子电机（菊花链：前左 → 前右 → 后右 → 后左，最后一个接 120Ω 终端）。
- 底盘 ESP32 → PWM → 4 块 BTS7960 → 4 个髋蜗轮电机；电机霍尔编码器、驱动电流 IS 回到 ESP32。
- 4 个 AS5600 地址一样（0x36），4 个 VL53L1X 也一样（0x29），一起经 TCA9548A 的 8 路接 ESP32 的 I2C。
- 屏幕板只当显示屏：它的引脚几乎全被屏幕、触摸占了，所以头部传感器继续接旧的那块 ESP32-S3。

## 底盘 ESP32-S3 建议引脚

| 功能 | 引脚 | 说明 |
|---|---|---|
| CAN TX / RX | GPIO 4 / 5 | 接 Adafruit CAN Pal（TJA1051） |
| I2C SDA / SCL | GPIO 8 / 9 | TCA9548A（→ 4 个 AS5600 + 4 个 VL53L1X）、INA226 |
| 前左髋 RPWM / LPWM | GPIO 10 / 11 | LEDC 20 kHz |
| 前右髋 RPWM / LPWM | GPIO 12 / 13 |  |
| 后左髋 RPWM / LPWM | GPIO 14 / 21 |  |
| 后右髋 RPWM / LPWM | GPIO 47 / 48 | v1.0 板的 48 接了彩灯，用 v1.1 板 |
| 4 个驱动使能（R_EN、L_EN 并一起） | GPIO 42 | 上电默认低：电机不动 |
| 电流 IS 前左 / 前右 / 后左 / 后右 | GPIO 1 / 2 / 6 / 7 | ADC1；每块驱动 R_IS、L_IS 各串 1k 并到一起 |
| 编码器 前左 A / B | GPIO 15 / 16 | PCNT |
| 编码器 前右 A / B | GPIO 17 / 18 |  |
| 编码器 后左 A / B | GPIO 38 / 39 |  |
| 编码器 后右 A / B | GPIO 40 / 41 |  |
| 急停检测（常开触点） | GPIO 43 | 不用 UART0 打日志，调试走 USB |
| 机身灯链（WS2812） | GPIO 44 | 经 5V 电平转换；腰线、尾灯、电机光环、前白灯串成一条（灯珠型号待定） |

不用的脚：0、3、45、46（启动用）、19/20（USB）、26–37（N16R8 的闪存和内存占用）。
