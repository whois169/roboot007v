# 零件尺寸收集清单

买一样、量一样，填进来。到本地以后让 Claude Code 读这份清单，按实测尺寸改模型，再重新生成打印文件，这样螺丝孔、卡槽、安装柱才对得上。

## 怎么收集（按准确程度排）
1. **卖家给的 3D 模型（STEP / STP 格式）**：最准，直接导进模型里对孔位。下单前先问客服"有没有 3D 模型或安装尺寸图"。
2. **带尺寸标注的图纸 / 详情页截图**：截清楚标数字的那张。
3. **自己用游标卡尺量**：单位 mm，量两次取平均。孔距量"两个孔中心之间"的距离：先量两孔外侧边缘的距离，再减去一个孔的直径。
4. **拍照**：零件正面、背面各一张，旁边放一把尺子。

每个零件记下：**店铺链接或型号**、**来源（模型 / 图纸 / 实测）**、下面列的尺寸。

> 带轮、张紧轮、髋座、外壳、支架这些是我们自己打印的，不用收集。

## 打印机校准（第一次打印前做一次）
同一个孔，不同打印机打出来的大小不一样。正式打印前先打一块**孔径测试片**（Φ3 / Φ4 / Φ5 / Φ8 / Φ19 孔各一个，还有一个热熔螺母孔），量一下实际打出来多大，螺丝、轴承、热熔螺母分别试装：
- [ ] 每种孔实际偏小多少：一般小 0.1–0.3mm
- [ ] 轴承压进去是太紧、刚好还是太松
- [ ] 热熔螺母烫进去以后牢不牢

把结果告诉 Claude Code，它会在模型里统一加补偿量。
