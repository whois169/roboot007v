# RoboDog v0.6 设计说明书

科技机械狗（不是宠物狗）。准直驱关节（无刷电机加 10:1 行星减速），走路安静、丝滑。外观按《外观设计规范 v1》：深灰哑光壳板 + 银色件 + 琥珀橙状态灯。大脑用云端多模态大模型当"任务调度员"，配合本地传感器，能巡检、测量、找东西、用红外控制家电。

## 2. 机身
- **骨架**：前后两个 PA-CF 打印的髋座，中间用 4 根 2020 铝型材连接。每个髋座里装 2 个外摆电机。
- **宽度**：机身宽 160mm（v0.4 从 140 加宽）。腿的位置没动，髋部电机一半嵌进机身轮廓、只露出一截。两个外摆电机之间、电子仓两侧多出来的空间先空着，留给走线和以后加东西。
- **中段**：
  - 下层：电池仓（底部 1/4 转快拆电池门）。电池已往前挪 23mm 配平。
  - 上层：MC02 主控，上面用铜柱叠树莓派；机身后段是配电模块、DC-DC 和 4010 排风扇。
- **散热**：顶甲前端进风，后端风扇排风，风从树莓派上方流过。髋座底盖开了散热槽。侧甲格栅只做浅槽装饰，不打通。任务箱底面离顶甲约 13mm，不堵排风口。
- **外观**（《外观设计规范 v1》）：深灰哑光 ASA 壳板，近黑 PA-CF 骨架，少量银色件，琥珀橙 WS2812B 状态灯。侧甲用缝线分成 3 块，后下方浅格栅，前上方一小段状态灯，上沿一条银色饰条。尾部是红色尾灯、急停按钮和充电口（v0.5 去掉尾鳍）。
- **背部任务系统**（v0.5）：
  - 两根任务导轨（中心 y=±66），每根 3 根立柱（x = −62 / 0 / +62）用 M5 直接锁进下面的 2020 型材；横杆顶面 z=94，下面离顶甲约 21mm，兼做提手。
  - 前段：激光雷达模块（桥板跨在两根横杆上，4 个下爪夹住；Φ60×35 单线雷达占位，扫描平面约 z=120；琥珀橙灯环）。雷达线从桥板下面走到顶甲左前的 Φ12 过线孔进机身。前方约 70° 会被头挡住，前方靠相机和测距补。
  - 后段：示范任务箱（88×112×34mm，翻边压在横杆上，4 个快拆夹；前面相机窗、后面 GX16 线缆口、顶面凹进去的提手），顶面不高过 z=116，不挡雷达。
  - 顶甲右后：GX16-8 任务接口（24V / 5V / CAN / USB，针脚见《电子系统与接线》4.1）。

## 3. 腿（每条 3 个电机）
| 关节 | 电机安装 | 传动 | 范围（已校核） |
|---|---|---|---|
| 外摆 HAA | 背面 4×M3（Φ38）装在髋座后壁 | 直驱 10:1 | ±30°（建议值，未校核） |
| 髋俯仰 HFE | 背面 4×M3（Φ38）装在髋支架上 | 直驱 10:1 | 站立、坐下、趴下 3 个姿态已校核（±85°） |
| 膝 KFE | **前端** 6×M3（Φ50）装在前安装环上，安装环套在大腿髋部 3 根立柱上 | HTD-5M 20mm 同步带，20T/36T = 1:1.8 | 膝内角 192° → 30° 全程无碰撞 |
| 外摆 HAA（实测扫描） | | | 前腿往里 15°、往外 30°；后腿内外各 25°（v0.5 没变） |

- **大腿 189.3mm、小腿 190mm**（v0.5 大腿缩短 0.7mm，见下面"皮带"）。大腿是一个封闭的盒子：实心内板 + 带围边的外壳（围边一直延伸到内板），膝电机、皮带、带轮、张紧轮都包在里面，从外面看不到皮带，也没有镂空。
  - **v0.6 外形（参考概念图）**：圆弧肩、上宽下窄。深灰大腿装甲和大腿外壳的轮廓**完全齐平**（髋端 R44 圆弧，两侧切线收到膝盖），2mm 底板 + 2.5mm 凸起中板（大斜切）+ 两道斜向折线 + 顶部琥珀橙状态灯 + 银色髋端盖。装甲在膝盖上方斜切收口，露出 Φ50 银色膝盖。
  - 外壳不能再放大：大腿板再宽就斜放不进 256 打印床。
  - **"叉形"大腿（没有槽口）**：髋部（z > −40）围边从外板包到内板；下半段围边只包皮带层（到隔板为止），小腿夹在隔板和内板之间活动。从侧面看是一整块完整的大腿；从正前方看能看到内板和隔板之间的缝（小腿就在里面）。
  - 张紧轮处外壳鼓出一个小包。张紧轮外侧用 M5 沉头螺丝（头和外板平齐），**调皮带时拆下大腿装甲**（4 颗 M3）。
  - 下端开槽口给小腿进出；小腿根部有一个膝部圆盘，槽口里有一块隔板挡住皮带，从槽口看进去是实心的。
  - 膝电机的线从内板的出线孔穿出来，再进机身。
- **髋罩**：上下两半，包住髋俯仰电机、电机插头和髋支架，跟着外摆关节一起动，不影响大腿转动。外侧电机孔前面一条竖向琥珀橙状态灯（着地 / 摆动 / 报错）。
- **皮带**：104 齿（520mm）PU 钢丝芯环形带，带张紧轮。电机峰值时皮带张力约 440N，正常步态建议在软件里把膝电机峰值限制在 6 N·m 左右。
  - **v0.5 修正**：v0.4 轴距 190mm 时需要 520.85mm，104 齿只有 520mm，装不上（张紧轮从外面压只会更长）。现在轴距 189.3mm，不压张紧轮需要 519.46mm；张紧轮名义压进 6.9mm 时刚好 520.01mm；长槽 ±6mm，能适应 519.5–521.4mm（打印误差 ±0.5mm 也够）。长度按皮带实际走线（绕过张紧轮）计算，`build.py` 每次都会检查。
- **膝关节峰值**：7 × 1.8 = 12.6 N·m。
- **小腿（v0.6 狗腿反弓）**：厚 32mm，实心；在膝下 90mm 处往后折约 30°（`config.py` → `LEG_STYLE = "C"`，另有 A 直、B 后弓可选）。弯折放在后侧：膝关节折叠时小腿前侧贴向大腿、后侧朝外，所以不影响折叠。弯折处受力最大，打印 6 层壁、60% 以上填充，P3 台架实测。
  - 外侧双色护甲：银色护甲（外形跟着小腿走，大斜切）+ 中间 1mm 深灰内嵌板（双面胶贴，盖住护甲螺丝）。
  - 球脚上方一个银色脚踝护圈（1 颗 M3 横向锁住）。
- **足端**：Φ36。TPU 95A 内芯用 M4 横销固定，外面套可更换的软胶防滑套。
- **站姿**：外摆关节内收 5°，脚往里收约 30mm，降低外摆电机的常驻力矩。

## 4. 脖子和头
- **偏航**：GM3506，±50°，装在前髋座顶上。
- **俯仰**：GM4108，抬头 15°、低头 25°。俯仰轴放在头部重心附近，静态力矩很小。v0.3.3 加了屏幕、头变大，头部重心前移，俯仰轴也跟着前移 12mm（x=184）；仿真里脖子电机最大 0.15 N·m，站立保持只要 0.02 N·m。抬头角度受轭架底板限制，需要再抬可以配合身体前仰。
- **联合限位**：头转得超过 40° 以后，能抬头的角度会变小（转到 50° 时只能抬头 2.5°），否则头后部会碰到机身；低头全程不受限。固件里按表限位，表见《电子系统与接线》。
- **眼睛**：一块 2.25 寸 76×284 长条 IPS 彩屏（ST7789，SPI，接 ESP32-S3），装在 2mm 深色亚克力面罩后面。v0.5 改成科技风 HUD：两块切角方块眼睛（表示看哪里）+ 扫描线 + 角标，青色为主，状态有待机、唤醒、聆听、思考、汇报、锁定目标、扫描、热成像、警告等（见《P1 头部开发计划》2.5 节）。
  - 屏幕玻璃正面贴着头壳内壁，背后用一个打印的压框和 2 颗 M2 自攻螺丝压住。
  - 按常见的蓝色转接板（73.15×21.08mm，8 针在一端）设计：玻璃左右居中对准面罩窗，转接板往左多出约 10mm 放排针，排针建议直接焊线。
- **前脸**（v0.5）：银色前脸面板框住屏幕，下面一块黑色传感器面板，所有前向传感器都开在这块面板上。
  - 黑色传感器面板从左到右（面对狗看）：红外接收、测距窗、相机镜头、隐私指示灯、MLX90640 热成像、红外发射。
  - **热成像、测距、红外收发都直接开孔**：亚克力挡远红外，也会削弱测距和红外遥控。屏幕下面这条只有约 11mm 净高，热成像的转接板要小（按 12×10.5mm 预留），到货后按实物改。
  - 相机用分体式 USB 模组（UVC 免驱）：镜头模组约 10×10mm，从背后塞进头壳里的方形座；软排线连到约 26×10mm 的小主板，主板贴在头壳右侧内壁。
  - LD2410B 毫米波（7×35mm 长条板）藏在屏幕上方的面板后面，毫米波能穿透塑料，不用开孔；面板上那道细缝是它的位置提示。
- **头内**：ESP32-S3、USB 集线器、2 × I2S 麦克风、功放加扬声器、BH1750 光照、隐私开关；头顶一片触摸铜箔，下巴那片贴在头壳下巴内侧。
- **外观**：深灰头壳加两圈缝线，银色前脸面板、黑色传感器面板，一对后掠耳鳍（左右通用件，以后可以换成天线造型）。

## 5. 电机接口（按店铺 V1.1 安装图）
- **外壳**：Φ57 × 45mm；输出凸台 Φ35，凸出 1mm。
- **输出端**：6×M3 深 5（分布圆 Φ27），加 3×Φ4 定位销（分布圆 Φ24.3）。
- **外壳前端**：6×M3 深 5（分布圆 Φ50），加 2×Φ3 定位销。
- **外壳背面**：4×M3 深 4（分布圆 Φ38）。
- **插头**：在侧面、靠近背面。外摆电机的朝斜上外侧，髋俯仰电机的朝外（前腿朝前、后腿朝后，v0.4 为了压低髋罩改的），膝电机的沿大腿朝下。插头空间已参与碰撞检查。
- **待核对**：孔的角度相位、插头的确切位置，见《电机实测清单》。

## 6. 校核结果
**CAD 碰撞检查**：站立、转头、坐下、趴下 4 个姿态都是 0 处干涉，包括插头、线束预留空间，以及 v0.5 新加的任务导轨、雷达模块、任务箱、GX16 接口。

**皮带长度检查**：通过（见第 3 节）。

**外摆关节范围**（每条腿单独扫 ±30°，留 1mm 间隙）：前腿往里 15°、往外 30°；后腿内外各 25°。v0.6 新腿没有缩小范围。

**膝关节全行程**（v0.6 新增 `check_knee.py`，每 5° 实体求交）：−10°…150° 全程无碰撞，能完全折叠。

**脖子联合限位**：站、坐、趴 3 个姿态重新扫描（v0.6），结果和 v0.4 的限位表完全一样（转头 40° 以内抬头 15°，45° 时 5°，50° 时 2.5°；低头全程 25°），雷达模块不碰头。

**MuJoCo 物理仿真**（简单关节 PD 控制）：
| 动作 | 结果 | 电机端扭矩 |
|---|---|---|
| 站立保持 | 机身 329mm，完全水平 | 外摆 0.4 / 髋俯仰 0.7 / 膝 1.5 N·m（平均），远低于 3 N·m 额定 |
| 站立 → 坐下 → 站起 | 成功 | 峰值 4.0 N·m |
| 站立 → 蹲伏 → 趴下 | 成功 | 峰值 5.5 N·m |
| 趴下 → 收腿蹲伏 → 站起 | 成功 | 髋俯仰峰值 7 N·m，顶到上限的时间约 6.0%（v0.5 是 6.1%，v0.4 是 5.4%；主要卡在收腿那一下） |
| 趴下后电机断电 | 平稳贴地 | 0 |

**结论**：结构不用改，但起身时髋俯仰电机余量偏紧，而且每加一点重量都会更紧。对策：①以后训练专门的起身动作时优化；②起身前先拆下任务箱（或软件里规定装着任务箱时不做趴下 → 起身）；③大腿外壳、隔板、壳板改用更轻的填充。

**重心**：站立时重心在足端中心后面约 10mm（v0.4 也一样），电池已经往前挪到头（+23mm）。站立很稳，走路时由步态控制器补偿；以后可以把配电板往前挪来改善。
