# RoboDog 行动清单（v0.5）

> v0.5：方向改成"科技机械狗"。P1 的目标从"会被摸开心的头"改成"能看、能测、能控制家电、会汇报的头"；新增 P6 建图导航。

思路：**不要一次凑 1.2 万。** 分 5 个阶段，每个阶段花一笔小钱，换一个看得见、能拿给人看的成果，再用这个成果去争取下一笔钱。
金额都是参考价，明细在《RoboDog_分阶段采购表.xlsx》里，买了一样就把"已买"改成"是"，表会自动算还差多少。

| 阶段 | 预算 | 累计 | 做完能看到什么 |
|---|---:|---:|---|
| P0 准备 | 0 | 0 | 仿真里的狗、展示视频、找到打印机 |
| P1 会说话的头 | ≈2,000 | ≈2,000 | 桌上一个能听、能说、能看、能测温、能用红外控制家电的头，科技风 HUD 眼睛，接云端大模型 |
| P2 单关节验证 | ≈1,200 | ≈3,100 | 1 个电机在桌上按你的程序转，量出真实孔位 |
| P3 一条腿 | ≈1,600 | ≈4,700 | 一条同步带腿装在台架上，能蹲起、能折叠 |
| P4 脖子 | ≈640 | ≈5,400 | 头能转、能点头，听到声音转头去看 |
| P5 整机 | ≈7,600 | ≈13,000 | 四条腿站起来、坐下、趴下、走起来；背部任务导轨和状态灯 |
| P6 建图导航（以后） | ≈280 起 | ≈13,200 | 背上装激光雷达模块，能在陌生的家里建图、自己走到指定房间 |

P1 预算比 v0.4 多，是因为加了热成像（约 200，可以晚点买）、红外收发、焊接工具和外观规范的三种颜色耗材。

P5 里最大的一笔是 9 个电机（约 5,850 元）。可以再拆成 3 次，每次买 3 个，正好是一条腿的量。

## P0 准备（0 元，现在就能做）
- [ ] 把 `viewer/robodog_v0.1.html` 和 `renders/` 里的效果图存到手机，随时能给人看
- [ ] 找打印机：学校实验室、创客空间、朋友家；实在没有就问淘宝代打 PA-CF 件的价格
- [ ] 软件先行：
  - 在电脑上装好 MuJoCo，用仿真模型练步态。仿真模型我可以从现在的 CAD 导出给你
  - 先把云端大模型对话、状态机、记忆这套"大脑"程序写起来，在电脑上就能跑
- [ ] 开一个开发日志账号（B 站、抖音、小红书任选），先发 3D 预览和设计过程
- [ ] 问达妙客服：DM-J4310 和 MC02 的教育优惠价、安装图纸（拿到孔位，模型就能定稿）

**完成标志**：有地方打印、大脑程序在电脑上能对话、发了第一条视频。

## P1 会说话的头（约 2,000 元）
为什么先做头：便宜，不用电机，你最擅长的软件部分全用得上，做出来就能演示"音箱做不到的事"，最适合拿去拉支持。
- [x] 树莓派 4B：已经有了
- [x] 先在笔记本上开发大脑：用笔记本自带的麦克风和摄像头跑通"唤醒 → 云端 → 说话"和"看到人才截图"，最后再移植到树莓派
- [ ] 头部零件（大部分已下单）：长条屏、亚克力面罩、OV5693 分体相机、ESP32-S3、2 个 INMP441、功放和 28mm 扬声器、USB 集线器、铜箔、隐私开关、VL53L5CX、LD2410B、BH1750、SHT40、BMI270、BMP280、线材、焊接工具
- [ ] **v0.5 新增**：红外发射管 + 红外接收头（几块钱，现在就买）；MLX90640 热成像（看预算）
- [ ] 零件到货后**量尺寸**，填进《零件尺寸收集清单》，让本地 Claude Code 按实测改头部模型，再打印
- [ ] 打印：先打孔径测试片；再打头壳、银色前脸面板、黑色传感器面板、屏幕压框、耳鳍、头部框架、桌面底座
- [ ] 软件：唤醒词 → 云端 → 汇报；摸头唤醒确认；HUD 眼睛 10 种以上状态；有人进屋自动锁定目标并汇报；红外学习和发码；热成像模式
- [ ] 录一段 1–2 分钟演示视频

**完成标志**：一个会汇报、会测温、能用红外控制家电的头，配一段视频。

## P2 单关节验证（约 1,200 元）
- [ ] 买：1 个 DM-J4310、MC02（或先用 USB2CAN）、24V 电源适配器
- [ ] MC02 固件：CAN 收发、MIT 模式、看门狗
- [ ] 量电机的真实孔位，填进 `cad/config.py`，重新生成全部零件
- [ ] 打印 1 个髋支架试装

**完成标志**：电机按程序做位置和力矩控制；模型孔位改成真实值。

## P3 一条腿（约 1,600 元）
> v0.6 腿：小腿是狗腿反弓，弯折处受力最大，打印 6 层壁、60% 以上填充；台架上重点看弯折处会不会裂、会不会弯。
- [ ] 买：再 2 个电机、1 根皮带、轴承、膝轴、螺丝套装、TPU
- [ ] 打印一条腿的全部零件：大腿两块板、带轮、张紧轮、小腿、足端、装甲和银色端盖
- [ ] 做台架，让腿做蹲起、折叠；调皮带张紧（v0.5：张紧轮名义压进约 7mm，长槽 ±6mm，不拆装甲就能调）；测膝关节力矩和温度

**完成标志**：腿能稳定蹲起 100 次，皮带不跳齿。

## P4 脖子（约 640 元）
- [ ] 买：GM3506、GM4108、2 块 SimpleFOC Mini、12V DC-DC
- [ ] 打印脖子底座和轭架；ESP32-S3 跑两个电机的 FOC
- [ ] 听到声音转头、看到人脸跟随

**完成标志**：头会转向说话的人。

## P5 整机（约 7,600 元，可以分 3 次）
- [ ] 分批买剩下 9 个电机（每次 3 个）
- [ ] 定做 6S2P 电池包（含 BMS），买配电件、急停
- [ ] 打印机身、装甲（深灰）、银色件、导光条；按照预览页里的布局装电子件和线束
- [ ] 装背部任务导轨（立柱 M5 锁进 2020 型材）和 GX16 任务接口；状态灯按《外观设计规范》的语义接好
- [ ] 顺序：先吊起来空跑，再趴下，再站起来，最后才跑仿真里训练好的步态

**完成标志**：站立 → 坐下 → 趴下 → 起身 → 走几步。

## P6 建图导航（以后，约 280 元起）
- [ ] 买 2D 激光雷达（LD06 / LD19 一类），按实物改雷达模块，装到导轨前段的桥板上
- [ ] 先不等狗会走：把雷达、陀螺仪、树莓派放在一块板上，用手端着在家里走一圈，跑通 ROS 2 + slam_toolbox 建图
- [ ] 建图放到局域网电脑上跑；地图库、进门识别、新环境先征得同意再扫描
- [ ] 接上步态：Nav2 只发"往哪走、走多快"，步态程序负责走

**完成标志**：在一个没来过的家里，扫描完成后说"去厨房"，它能自己走过去。

## 钱从哪来（按靠谱程度排）
1. **用自己的技能挣第一笔**：你说软件简单，接一两个小外包（小程序、脚本、网站）或做家教，凑 P1、P2 最快。
2. **家人、朋友**：按阶段要，不要一次开口要 1.2 万。先要 P1 的 1,400，做出会说话的头给他们看，再要下一阶段。下面有一段可以直接改了用的话。
3. **学校、单位的创新经费**（如果你是学生）：大学生创新创业训练计划（大创）、学院科创基金，还可以借实验室的打印机和电源。具体金额和申报时间以学校当年通知为准。
4. **比赛**：挑战杯、中国机器人大赛、地方创客大赛等，有的有奖金或配套经费。规则以每年官方通知为准。
5. **厂商赞助和优惠**：给达妙、打印耗材品牌、嘉立创这类厂商发邮件，附上 3D 预览和视频，申请教育价、样品或赞助，回报是开源和视频鸣谢。一些平台有开源硬件激励活动，以平台公告为准。
6. **二手**：闲鱼上的树莓派、RoboMaster 队伍赛季后出的二手电机，能省 20–40%。买二手电机要让卖家现场转给你看。
7. **开发日志**：持续更新视频，攒到一定关注以后，接厂商的零件赞助。

**不建议**用网贷、信用卡分期买零件。项目周期长，中途很可能要改设计，背着利息压力不值得。
