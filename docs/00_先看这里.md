# RoboDog v0.6 完整资料

这是目前**最新、唯一需要保存的一份**，之前发过的所有压缩包都可以删掉。

> **最重要的一份文件：`00_项目核心原则.md`。** 我们做的是"科技机械狗"，不是宠物狗，也不是"装了个音箱的机器狗"，每个版本都要对照它检查。以后找 Claude 继续做，开新对话时先把它发过去。外观按 `07_设计说明/外观设计规范.md`。

## 一句话
科技机械狗：腿上 12 个达妙 DM-J4310 准直驱关节（膝关节用同步带），脖子 2 个云台电机，眼睛是一块 2.25 寸长条彩屏（科技风 HUD），头上有热成像和红外遥控收发，背上有任务导轨（激光雷达模块 + 任务箱）。树莓派 5 加 MC02 做控制，大脑用云端大模型当任务调度员。3D 打印骨架，深灰 + 银 + 琥珀橙的工业风外观；腿的造型参考概念图（圆弧肩大腿、外露银色膝盖、反弓小腿）。站立、坐下、趴下、起身，在 CAD 碰撞检查和 MuJoCo 物理仿真里都验证过了。

## 重新生成（改了 `cad/config.py` 之后）
```bash
pip install cadquery trimesh mujoco
cd 08_源码与生成脚本/cad
python3 build.py --check       # 全部 STL、STEP、碰撞检查、皮带长度检查（约 15 分钟）
python3 export_sw.py           # SolidWorks 文件
python3 export_mujoco.py       # MuJoCo 模型
python3 ../viewer/make_viewer.py
```
生成的文件会放在 `08_源码与生成脚本/out/` 下。
