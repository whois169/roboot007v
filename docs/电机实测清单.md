# 电机到手后要核对的尺寸

> 主要尺寸已经按店铺的 V1.1 安装图填进模型（v0.3.2）。电机到手后只需要核对下面几项，特别是**孔的角度相位**和**插头位置**，图上看不清。

量完把数字填给我，或者直接改 `cad/config.py` 里的 `MOTOR`。最好的办法是问达妙客服要**安装尺寸图**和 **3D 模型（STEP）**，那样就不用自己量了。

用游标卡尺量，单位 mm。

## 输出端（银色法兰，带动腿的那一面）
- [ ] 法兰外径
- [ ] 法兰比黑色外壳凸出多少（量高度差）
- [ ] 螺丝孔数量，螺纹规格（拿 M3 / M4 螺丝试拧）
- [ ] 螺丝孔分布圆直径：量两个正对着的孔的中心距。孔是奇数个时，告诉我孔数和相邻两孔的中心距
- [ ] 螺纹孔深度（能拧进去多深）
- [ ] 中心孔（轴承）内径；有没有定位止口或定位销孔，有的话量直径
- [ ] 三个凹坑：是减重坑还是装配用的，有没有螺纹

## 外壳前端（黑色那一圈）
- [ ] 外壳外径、总高度（不含法兰）
- [ ] 这一圈的孔：数量、螺纹、分布圆直径、深度
- [ ] 外壳边上的缺口：位置、宽度。拍一张正对着的照片，旁边放一把尺子

## 外壳背面
- [ ] 背面有没有安装孔：数量、螺纹、分布圆直径
- [ ] 出线口 / 插头的位置：在背面还是侧面，朝哪个方向，插头是什么型号（XT30 2+2 之类）

## 重量和标签
- [ ] 单个电机重量（厨房秤就行）
- [ ] 外壳标签上的完整型号

## 拍照
- [ ] 正面、背面、侧面各一张，旁边放尺子
- [ ] 插头特写一张
