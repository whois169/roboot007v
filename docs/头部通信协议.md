# 头部通信协议（树莓派大脑 ↔ 头部 ESP32-S3）

> 写 ESP32 固件的人看这份。大脑这边的代码：`brain/dog/protocol.py`（事件检查）、`brain/dog/hud.py`（屏幕指令检查和渲染）、`brain/dog/eyes.py`（串口收发）。

## 怎么连
- 一根 USB 线，走 USB 串口（CDC），波特率 115200（`brain/config.yaml` → `eyes.serial`）。
- 两个方向都是**一行一条 JSON**：UTF-8 编码，`\n` 结尾，一行不超过 512 字节。
- 收到看不懂、不合规的行，直接丢掉，不要卡住。大脑那边也一样，丢掉时会在日志里写原因。

## 大脑 → ESP32：屏幕指令
字段都可以省略，只发要改的部分。

```
{"mode":"track","gaze":[0.3,-0.1],"level":0.6}
{"mode":"error","text":"E-NET","hold":2.5}
{"status":{"temp":22.1,"sim":true,"bat":null}}
{"log":["FACE 1 MOT 0.02"]}
```

| 字段 | 意思 |
|---|---|
| `mode` | 12 个状态之一：idle wake listen think speak track scan thermal alert error sleep low_bat |
| `gaze` | 视线 `[x, y]`，范围 -1 到 1。x = -1 是狗的左边；y = -1 是上，+1 是下 |
| `level` | 0 到 1。聆听时表示麦克风音量，汇报时表示语音音量 |
| `text` | 提示文字，最多 14 个字符，换模式时自动清掉 |
| `hold` | 这个模式至少保持几秒，期间来的模式切换先排队 |
| `status` | 屏幕边上的状态：`temp` 温度，`sim` 是否假数据，`bat` 电量（`null` 表示不知道） |
| `log` | 往数据流里加几行，每行最多 52 个字符，只能用英文大写、数字和少量符号 |

每个状态长什么样、画法有哪些限制，看 `brain/README.md` 的第②块。固件里的渲染器照着 `hud.py` 翻成 C++ 就行，字体数据可以直接拷过去。

## ESP32 → 大脑：事件
每条都带 `ev` 字段。

| 事件 | 例子 | 什么时候发 |
|---|---|---|
| hello | `{"ev":"hello","fw":"0.1.0","caps":["touch","light"]}` | 开机或重连时发一次，写明固件版本和有哪些功能 |
| hb | `{"ev":"hb","up":1234}` | 心跳，**每秒一次**；`up` = 开机多少秒。大脑 3 秒收不到，就认为头部掉线了 |
| touch | `{"ev":"touch","zone":"head","action":"tap"}` | 触摸。`zone`：head 头顶 / chin 下巴。`action`：tap 点一下 / hold 按住满 1 秒（按住时就发）/ release 按住以后松开 |
| sensor | `{"ev":"sensor","name":"light","value":120.5,"unit":"lux"}` | 传感器读数，变化明显时发，最多每秒一次 |
| privacy | `{"ev":"privacy","on":true}` | 隐私开关拨动时发一次，开机时也发一次。`on: true` = 拨到"隐私"，这时相机和麦克风已经**硬件断电** |
| error | `{"ev":"error","code":"I2C","text":"BH1750 no ack"}` | ESP32 自己出错 |

触摸的规矩：只按了一下就松开，松开时发 `tap`；按住满 1 秒，当场发 `hold`，松开时再发 `release`。

### 传感器名字（sensor 的 name）
| name | 是什么 | 单位 | 装在哪 |
|---|---|---|---|
| light | 环境光照 | lux | 头顶光照窗（BH1750） |
| distance | 前方最近物体距离 | mm | 前脸测距窗（VL53L5CX） |
| presence | 毫米波检测到有人 | true / false | 屏幕上方（LD2410） |
| presence_distance | 毫米波测到的人的距离 | cm | 屏幕上方（LD2410） |
| head_temp | 头内温度（不是屋里温度） | °C | 头壳里 |
| ir_code | 学到的红外码 | 文字 | 前脸红外接收头 |
| thermal_max / thermal_min | 热成像最高 / 最低温度 | °C | 前脸热成像（MLX90640） |

要加新传感器：先在 `brain/dog/protocol.py` 的 `SENSORS` 表里加一行，再更新这张表。

## 大脑收到事件后做什么
- **摸头顶（tap）**：平时是唤醒并确认，马上响提示音、屏幕闪 `[ONLINE]`、开始听，不用看着它，也不用喊唤醒词。如果它正在想或正在说，就马上停下来听你说。
- **摸下巴（tap）**：它在想或在说时，停下来待机；它在听时，不听了。
- **长按**：暂时只记一笔，以后再定用途。
- **隐私开关打开**：不听、不看、不主动说，屏幕显示 `PRIVACY`；拨回来恢复。
- **传感器读数**：放进感觉板，大模型回答时能看到，比如"头顶光照 120 lux（来源：头部 ESP32 传感器）"。

## 在电脑上模拟（没有 ESP32 时）
HUD 模拟器窗口里用键盘代替：**T = 摸头顶，C = 摸下巴**（按住 1 秒以上 = 长按），**P = 拨隐私开关**。按键产生的事件也是先变成一行 JSON 文字，再走和真串口一样的解析和检查。
