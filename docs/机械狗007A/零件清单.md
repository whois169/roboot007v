# 机械狗007A 零件清单

> 由 `007a/bom.py` 生成（改清单改那个文件，再跑 `python 007a/bom.py`）。价格是国内零售大概价，以下单时为准。
> 批次：**样品** = 先买 1 个（电机先买 1 条腿的 3 个）测试；**第二批** = 样品测过再买齐；**第2步定** = 结构件，等骨架图纸；**沿用** = 007v 已有。

**样品这一批约 12570 元；样品合格后第二批约 18780 元；第 2 步结构件约 540 元起**（不含沿用的树莓派；铝板、车削件、打印耗材第 2 步出图后再算）。

## 下单时要问卖家要图的（★）

- **电机 USB 转 485 模块**（宇树官方 485 转 USB 模块（手册里的配件 A））：价格估的；问卖家要尺寸（要装进机身托板）
- **红外热像仪**（艾睿光电 Tiny1-C 256 × 192（要带 USB 转接板的版本））：要问卖家：USB 转接板的尺寸和孔、镜头视场选哪个（建议 50° 左右）；镜头前面直接开孔，不能挡亚克力（亚克力挡远红外）
- **气体检测**（炜盛 ZCE04B 四合一（CO / H₂S / O₂ / CH₄））：安装孔问卖家；手册写“不要用在涉及人身安全的系统里”→ 只当预警，人进管道前要用合格的手持检测仪；第一次用要通电老化 24 小时
- **IMU**（超核 HI13（USB-C 外壳版，选 HI13M3 一类 ±2000°/s））：安装孔官网没写，问卖家或下载中心 download.hipnuc.com 找规格书；装在机身正中、靠近重心
