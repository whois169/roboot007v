# RoboDog 外观设计规范 v1.1（v0.5 起执行，v0.6 加了腿的造型规矩）

> 以后所有新零件都按这份规范做。参考风格：ChatGPT 概念图里的"04 工程任务犬"（身体和腿）+"03"的背部激光雷达塔。
> 原则：**效果图里的每一块，都必须能 3D 打印出来、装上去。** 好看靠设计手法，不靠金属加工。

## 1. 风格一句话
方正箱体，深灰哑光壳板层叠在骨架上；全部是平面和斜切角，没有圆滑曲面；银色件只用在少数"点睛"的位置；琥珀橙状态灯每处只有一小条。

## 2. 配色和材质（效果图按这几组上色）

| 分组 | 颜色 | 用在哪 | 打印材料 |
|---|---|---|---|
| 壳板 | 深灰 #3D4147，哑光 | 机身侧甲、顶甲、尾罩、肩甲、髋罩、大腿装甲、头壳、耳鳍、任务箱 | ASA 深灰哑光（户外不褪色）；室内用 PETG 哑光深灰也可以 |
| 银色件 | 银 #C4C8CD | 前脸面板、髋端盖、膝端盖、小腿护甲、侧面饰条、任务箱快拆夹 | PETG/PLA 银色；或任意料打印后先喷灰底漆再喷金属银自喷漆 |
| 黑色窗口 | 黑 #0B0C0E | 头部传感器面板、任务箱相机窗、激光雷达 | PETG 哑光黑 |

**用量规矩**：银色件面积不超过外观总面积的 15%；琥珀橙灯每处一小条，不要整圈都亮。

## 3. 形体规矩
- **斜切角代替圆角**：外露的棱边一律斜切。大面板边缘 2.0mm，小件 0.8–1.5mm；凸起的中板用 2.2mm 大斜切做出"折面"感。
- **层叠**：一块大平面不要直接做平，分成"底板 + 凸起中板"两层（例：大腿装甲 2mm 底板 + 2.5mm 中板）。
- **缝线**：凹槽 **0.8mm 宽 × 0.6mm 深**，打印出来就有，不用后期加工。每块大面板至少 1–2 道，把它分成几块看起来像拼起来的。缝线不能切穿壁厚，壁厚 ≥2mm 的地方才能开。
- **格栅**：装饰格栅做浅槽（1.0–1.2mm 深），不要打通侧壁，免得侧面漏风抢走流过电子件的风。真正的进/排风格栅只在顶甲。
- **黑色传感器面板**：所有朝外的传感器窗口集中开在一块黑色面板上，用细分隔线分开，像设备面板。

## 3.1 腿的造型（v0.6，参考概念图 04 的腿）
- **大腿：圆弧肩、上宽下窄、表面平整**。大腿装甲的外形和大腿外壳的轮廓**完全齐平**（髋端 R44 圆弧，两侧顺着切线收到膝盖），外面不能有一圈凸边。装甲在膝盖上方斜切收口，让银色膝盖露出来。
  - 大腿外壳不能再放大：大腿板再宽就斜放不进 256 打印床。想要更宽的肩，只能把大腿板拆成两块拼接（会多一道接缝、强度变差，不建议）。
  - 装甲表面：2mm 底板 + 2.5mm 凸起中板（2.2mm 大斜切）、两道斜向折线、顶部一小段琥珀橙状态灯、银色髋端盖。**装甲上不开调节孔**，调皮带时拆下装甲（4 颗 M3）。
- **大腿没有槽口（"叉形"大腿）**：髋部（z > −40）围边从外板一直包到内板；下半段围边只包皮带那一层，到隔板为止。小腿夹在隔板和内板之间活动，从侧面看是一整块完整的大腿。
- **膝盖外露**：Φ50 银色膝盖（端盖 + 垫环，3 颗 M2 自攻锁在大腿外板上），中间深色凹槽 + 一圈细环线。
- **小腿：狗腿反弓**（`config.py` → `LEG_STYLE = "C"`）：小腿在膝下 90mm 处往后折约 30°，弯折都放在后侧（折叠时朝外），所以不影响膝关节折叠。另有 A（直）、B（后弓小腿肚）两种造型可选，改 `LEG_STYLE` 就能切换。
  - 小腿杆身弯折处受力最大，打印时 **6 层壁、填充 60% 以上**，P3 台架上实测强度。
- **小腿护甲双色**：银色护甲（外形跟着小腿走）+ 中间深灰内嵌板（1mm，双面胶贴，顺便盖住护甲螺丝）。
- **银色脚踝护圈**：套在小腿末端、足端上面，1 颗 M3 横向锁住。
- **硬规矩**：任何腿部造型改动，都要跑 `check_knee.py`，膝关节必须保持 −10°…150° 全程无碰撞（摔倒后自己爬起来、坐下、趴下都靠它）。

## 4. 固定方式（所有外观件通用）
- 外观件**只管外观、不承力**，力全部走骨架（髋座、型材、大腿内外板、小腿）。
- 每块壳板能**平放打印**、放进 256×256×256 床，壁厚 ≥2mm。
- 大件用 **M3 热熔螺母**固定到骨架上；小件（端盖、前脸面板）用 **M2 自攻螺丝**直接拧在下面那块打印件上。
- 改了外观件，必须重跑：`build.py --check`（4 个姿态 0 干涉）、`check_haa.py`（外摆范围不能变小）、`check_neck.py`、MuJoCo 扭矩检查（外壳加重了，起身的扭矩不能变差太多）。

## 5. 状态灯语义（软件按这个点亮）
| 位置 | 常亮 | 慢闪 | 快闪 |
|---|---|---|---|
| 髋罩灯（每条腿一条） | 这条腿着地 | 这条腿在摆动 | 这条腿的电机报错 |
| 机脊灯（左右各 3 段） | 待机 | 执行任务中（流水灯表示前进方向） | 低电量 / 警告 |
| 侧面灯 | 正常 | 联网中 | 断网 |
| 雷达灯环 | 雷达在转 | 正在建图 | 雷达故障 |
| 任务箱灯 | 模块已连上 | 模块在工作 | 模块报错 |

颜色统一琥珀橙；只有尾灯是红色（刹车 / 急停）。

## 6. 背部任务接口标准
- **机械**：两根任务导轨（左右各一，中心 y = ±66mm），横杆截面 12×10mm，横杆顶面高 z = 94mm，下面离顶甲约 21mm，**兼做提手**。每根导轨 3 根立柱，用 M5 螺丝直接锁进下面的 2020 型材（x = −62 / 0 / +62mm）。
- **模块固定**：模块的翻边压在两根横杆上，用 4 个快拆夹（银色）夹住横杆。
- **电气**：顶甲右后斜面一个 **GX16-8 航空插座**（位置 x = −80、y = −34），提供 24V、5V 电源和 CAN、USB 信号。模块用一根短线插过来。针脚定义在《电子系统与接线》4.1 节。激光雷达模块的线从桥板下面走到顶甲左前的 Φ12 过线孔进机身。
- **高度规矩**：激光雷达模块装在导轨前段的桥板上，扫描平面大约在 z = 120mm。**导轨后段的模块顶面不能高过 z = 116mm**，否则会挡住雷达后方的视野。更高的模块（比如以后的机械臂）装上时，雷达模块挪到它上面或者暂时拆掉。
- 现有模块：激光雷达模块（Φ60 单线雷达占位，买前按实物改）、示范任务箱（88×112×34mm，前面相机窗，后面 GX16 线缆口，顶面凹进去的提手）。

## 7. 和概念图的差别（为什么不完全照搬）
- **保留我们自己的头**：概念图 04 没有独立的头，而头是我们的感知中心（屏幕眼睛、相机、热成像、红外遥控）。头的前脸借用了 04 的"银色面板框住黑色传感器窗口"。
- **电机露不出来**：我们的 12 个关节电机都在髋座、髋罩和大腿里面，强行露出来会碰到线和外壳。改用**银色髋端盖、外露的银色膝盖**做出同样的"金属关节"效果。
- **大腿比概念图粗一点**：膝盖那头里面要装大带轮，最窄只能 68mm；肩部受打印床限制最宽 88mm。
- **没有侧面开窗、没有楔形前脸**：按总指挥的选择去掉。
- **任务箱比概念图扁**：因为不能挡住激光雷达（见第 6 节）。
- **去掉了尾鳍**：尾鳍是宠物元素，和"科技机械狗"的方向不符。耳鳍暂时保留（头的辨识度），以后可以换成天线造型。
