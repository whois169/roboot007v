# RoboDog v0.3.3

> **核心原则**：不是"装了个音箱的机器狗"。所有设计按 `docs/00_项目核心原则.md` 检查。

四足机器狗结构框架：腿上 12 个 DM-J4310-2EC 准直驱关节，脖子 2 个云台电机。3D 打印骨架，机身用 2020 铝型材。

## v0.3 改动
- **膝关节改成同步带**：HTD-5M 20mm 宽 PU 钢丝芯皮带，20T/36T，1:1.8，带张紧轮。膝关节内角能从 192°（略微反折）一直折到 30°，所以能坐下、趴下。膝关节峰值约 12.6 N·m。
- **大腿、小腿从 200mm 缩到 190mm**：加宽后的大腿板因此还能斜放进 256 的打印床。
- **2 自由度脖子**：GM3506 负责偏航（±50°），GM4108 负责俯仰（抬头 15°、低头 25°）。俯仰轴放在头部重心附近，静态力矩很小。
- **新头部**：
  - USB 相机
  - ESP32-S3 语音前端：本地唤醒词、回声消除
  - 2 个 I2S 麦克风，功放加 28mm 扬声器
  - 传感器：VL53L5CX 测距、LD2410 毫米波、BH1750 光照
  - 隐私拨动开关（硬件直接给相机和麦克风断电）加指示灯
  - 穿过脖子的线只有 1 根 USB 加 1 对电源线
- **感知**：
  - 4 个触摸区：头顶、下巴、背部前后
  - 前后各一个防跌落 ToF
  - INA228 测电池电压电流，2 个 NTC 测温
- **站姿**：外摆关节内收 5°，降低外摆电机的常驻力矩。电池往前挪 23mm 配平。
- **线束和散热**：
  - 髋座前壁开线束口，髋座底盖开散热槽
  - 侧甲斜槽只做装饰，不打通，避免空气从侧面抄近路，抢走流过树莓派的风

## v0.3.1 微调
- **小腿加粗**：前后宽度 30→38mm（脚端 18→24mm），厚度 24→32mm，中间保留减重长孔。外侧加一块白色护甲。
- **防滑足端改成两件**：TPU 95A 内芯用 M4 横销固定，外面套一个可更换的软胶防滑套（TPU 85A，或者用打印模具浇 40A 硅胶），表面有浅横纹和竖纹，适合室内光滑地面。球径 32→36mm。

## v0.3.2：电机按 DM-J4310 V1.1 安装图更新
- **外壳**：Φ57，长 45mm；输出凸台 Φ35，凸出 1mm。
- **输出端**：6×M3 深 5，分布圆 Φ27；另有 3×Φ4 定位销，分布圆 Φ24.3。髋支架、大腿内板、带轮转接盘都加了对应的定位销孔。
- **外壳背面**：4×M3 深 4，分布圆 Φ38。外摆电机靠这组孔装在髋座后壁上，髋俯仰电机靠它装在髋支架上。
- **膝电机改成前端固定**：背面那组 Φ38 孔会被髋俯仰电机的 Φ35 法兰挡住，拧不进螺丝，所以新增"膝电机前安装环"。安装环用 6×M3 锁在电机外壳前端的 Φ50 孔上，再套在大腿髋部的 3 根立柱上。
- **插头**：插头在外壳侧面。每个电机的插头座和插上线以后的空间（按直角插头算）都画进去了，并且参与碰撞检查。外摆电机的插头斜向上外侧，髋俯仰电机朝上，膝电机沿大腿朝下。
- **待核对**：孔的角度相位图上没标清，装配前对一下实物。

## v0.3.3：眼睛换成长条彩屏，传感器收进前脸
- **眼睛**：原来的两段 WS2812 灯条只能变色、闪烁，换成一块 2.25 寸 76×284 长条 IPS 彩屏（ST7789，SPI，接 ESP32-S3），能画动画眼睛。装在 2mm 深色亚克力面罩后面，玻璃贴着头壳内壁，背后用打印的屏幕压框和 2 颗 M2 自攻螺丝压住。按常见的蓝色转接板 73.15×21.08mm 设计。
- **传感器收进前脸，不加鼻子**：屏幕下面那条白边上从左到右（面对狗看）依次是测距窗、相机镜头、隐私指示灯。相机换成分体式 USB 模组：镜头模组约 10×10mm，用软排线连到 26×10mm 的小主板，主板贴在头壳右侧内壁。LD2410B 毫米波（7×35mm 长条板）藏在屏幕上方那条白边后面，不用开孔。（中间试过一版单独的"鼻子"，和眼睛不协调，已经取消。）
- **头壳**：前脸加宽加高（宽 80→92mm，高 34→46mm），给屏幕转接板留位置。
- **WS2812 灯带**：只用在机身上（脊灯、侧灯、尾灯），挪到 P5 采购。
- **俯仰轴前移 12mm**（x 172→184）：加了屏幕、头变大以后重心往前移，不挪的话仿真里脖子电机在坐下、起身时有 12–20% 的时间顶到力矩上限。挪了以后不再顶到上限，站立时只需要 0.02 N·m。
- **脖子联合限位**：扫描了转头和低头/抬头的全部组合。头转超过 40° 以后再抬头，头后部会碰到机身（这是旧版本就有的问题，这次查出来了）；低头全程不受限。用软件限位解决，表在 `cad/head.py` 的 `NECK_LIMITS` 和《电子系统与接线》里。

## 目录
- **MuJoCo 仿真**：`out/mujoco/scene.xml`。站立、坐下、趴下、起身都已在仿真里验证过，见 `out/mujoco/README.md`；动画在 `renders/mujoco_sequence.gif`
- **SolidWorks 运动分析**：`out/solidworks/robodog_v0.3.3_rigid_groups.step`（零位，15 个刚体分组）、`out/solidworks/关节表.csv`、`out/solidworks/刚体质量.csv`。操作步骤见 `docs/SolidWorks运动分析说明.md`
- `docs/电机实测清单.md`：电机到手后要量的尺寸
- `docs/行动清单.md`：分 5 个阶段的行动清单，以及资金从哪来
- `docs/RoboDog_分阶段采购表.xlsx`：分阶段采购表（参考价），买了一样就标"已买"，自动算还差多少
- `cad/config.py`：所有关键尺寸，**改这里就行**
- `cad/parts.py`：机身和髋部结构件
- `cad/leg.py`：同步带腿（大腿板、带轮、皮带、张紧轮、小腿）
- `cad/armor.py`：外观装甲和灯条
- `cad/head.py`：脖子和头部（含头内电子件）
- `cad/build.py`：生成全部文件，加 `--check` 会对每个姿态做干涉检查
- `cad/export_sw.py`：生成 SolidWorks 用的分组装配体、关节表、质量表
- `cad/export_mujoco.py`：生成 MuJoCo 仿真模型
- `cad/check_neck.py`：脖子转头 × 低头/抬头全范围扫描（需要 python-fcl）
- `out/stl/`：v0.3.3 打印件（45 种，共 84 件）。`out/archive/` 里是旧版
- `out/step/robodog_v0.3.3_stand.step`：站立姿态整机
- `out/robodog.glb` + `out/rig.json`：按刚体分组的模型和关节数据，网页预览靠它们摆姿态，以后导出 URDF 也用它们
- `out/report.txt`：皮带、重量、重心、各姿态着地点、干涉检查、打印件清单
- `viewer/robodog_v0.1.html`：3D 预览（文件名沿用旧的，内容是 v0.3），支持站立、转头、坐下、趴下 4 个姿态
- `renders/`：效果图（站立、转头、坐下、趴下、腿、头、机身、感知、足端、电机接口）

## 重新生成
```bash
pip install cadquery trimesh mujoco
cd cad && python3 build.py --check     # 约 10 分钟
python3 export_sw.py
python3 export_mujoco.py
python3 ../viewer/make_viewer.py
```

## 到货后核对
- 电机：孔的角度相位、插头位置，见 `docs/电机实测清单.md`
- 长条彩屏：转接板尺寸、玻璃在板上的位置、排针在哪一端（`head.py` → `SCREEN`）
- USB 相机：板子尺寸和 4 个安装孔的孔距（`head.py` → `CAM_POSTS`），镜头长度
- `config.py` → `MC02`：主控板尺寸
- `head.py` → `GM3506` / `GM4108`：安装孔位
- 皮带：确认能定制 104 齿（520mm）的 20mm 宽环形带

建议先打一条腿试装，再批量打印。
