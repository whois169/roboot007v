# RoboDog MuJoCo 仿真模型（v0.3.3）

由 `cad/export_mujoco.py` 从 CAD 自动生成。改了 CAD 以后重新运行它，这个文件夹会整体更新，不要手改 xml。

## 快速开始（在你的电脑上）
```bash
pip install mujoco
python -m mujoco.viewer --mjcf scene.xml     # 只看模型，可以拖动关节
python demo.py                               # 自动循环：站立 → 转头 → 坐下 → 站起 → 蹲伏 → 趴下 → 收腿蹲伏 → 站起
python check_poses.py                        # 无界面检查，打印机身高度和各关节电机力矩
```

## 模型里有什么
- **15 个刚体、14 个关节**：4 条腿 × 3（外摆 haa、髋俯仰 hfe、膝 knee），脖子 2 个（neck_yaw、neck_pitch）。另有 1 个浮动基座 root。
- **质量和惯量**：按 CAD 实体逐个零件计算，总质量 8.74kg。外购件按公开质量；打印件按材料密度乘填充率。
- **执行器**：14 个力矩电机，`ctrl` 是**电机端**力矩，单位 N·m，限幅 ±7（DM-J4310 峰值）。膝关节 `gear=1.8`，对应同步带减速，关节端力矩是 1.8 倍。脖子限幅 ±0.15 N·m。
- **关节参数**：armature（转子惯量）、阻尼、摩擦都是估算值，拿到实物后建议辨识一下。
- **传感器**：
  - IMU：姿态四元数、陀螺仪、加速度计
  - 4 个足端触地
  - 3 个测距：前向 ToF，前后防跌落 ToF
  - 头部相机 `head_cam`
- **碰撞**：机身盒子、腿部胶囊、足端球（摩擦 0.9），只和地面碰撞，不算自碰撞。
- **关键帧（5 个）**：stand 站立、look 转头、sit 坐下、lie 趴下、crouch 收腿蹲伏。

## 已验证（简单 PD 控制，不是步态策略）
| 动作 | 结果 | 电机端最大力矩 |
|---|---|---|
| 站立保持 | 机身 330mm，完全水平 | 外摆 0.4 / 髋俯仰 0.5 / 膝 1.4 N·m（持续） |
| 坐下再站起 | 成功 | 髋俯仰峰值 3.7 N·m |
| 站立 → 蹲伏 → 趴下 | 成功，机身触地速度约 0.06 m/s（轻轻放下） | 髋俯仰峰值 5.1 N·m |
| 趴下 → 收腿蹲伏 → 站起 | 成功 | 髋俯仰峰值 7 N·m，顶到上限的时间约 0.6% |
| 趴下后电机断电 | 机身平稳贴地 | 0 |

注意：**趴下和起身都要经过蹲伏（crouch）**。腿伸直的时候杠杆最长，髋俯仰电机最吃力；先把腿收到身体下面，力矩就小很多。直接从站立趴下也能成功，但髋俯仰电机峰值会到 7 N·m。
